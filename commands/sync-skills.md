# Sync Global Skills

将 codeskill 部署到 `~/.claude/skills/` 并链接到所有 Agent。

```bash
~/Documents/code/rule/sync-global-agent-standards.sh
```

完成后确认：

- `~/Documents/code/skill/codeskill/` 已部署到 `~/.claude/skills/`
- `~/.agents/skills/`、`~/.codex/skills/`、`~/.workbuddy/skills/`、`~/.trae-cn/skills/`、`~/.codebuddy/skills/`、`~/.cursor/skills/` 已链接到 `~/.claude/skills/`
